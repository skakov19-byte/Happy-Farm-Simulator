# ДОПОЛНЕНИЕ К ПРОМТУ: Визуальная полировка

Добавь систему частиц и улучшенных анимаций для повышения "сочности" игры.

## ТРЕБОВАНИЯ

### 1. Частицы воды (Экран: Колодец)
- При клике на колодец создавай 5-10 частиц воды (голубые круги)
- Частицы разлетаются в случайных направлениях
- Анимация: появление → движение вверх → исчезновение (fade out)
- Длительность: 500ms
- Используй Canvas API или CSS-анимации

### 2. Частицы монет (Экран: Рынок)
- При продаже товаров создавай 10-15 золотых частиц
- Частицы летят от товара к счётчику монет в шапке
- Анимация: параболическая траектория
- Звук: "дзынь" при достижении счётчика

### 3. Floating text (везде)
- При получении ресурсов показывай всплывающий текст: "+5 💧", "+10 🪙"
- Текст появляется над объектом, движется вверх, исчезает
- Цвет текста соответствует типу ресурса (вода — синий, монеты — золотой)
- Длительность: 1 секунда

### 4. Улучшенные анимации растений
- Стадии роста: плавная трансформация эмодзи (scale + fade)
- При сборе урожая: растение "встряхивается", плоды падают вниз
- Добавь лёгкое покачивание растений (CSS animation: sway)

### 5. Hover-эффекты
- Все кнопки: scale(1.05) при наведении, scale(0.95) при клике
- Плавные transitions: 200ms ease-out
- Тень под кнопками увеличивается при hover

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
- Создай новый файл: /js/particles.js
- Интегрируй в существующие экраны
- Не ломай текущую функциональность
- Оптимизация: максимум 50 частиц одновременно

## КРИТЕРИИ ГОТОВНОСТИ
1. При клике на колодец видны брызги воды
2. При продаже на рынке летят монеты к счётчику
3. Всплывающие числа видны при любом получении ресурсов
4. Растения плавно анимируются
5. Все кнопки имеют приятные hover-эффекты
6. Нет просадок FPS (проверить в DevTools → Performance)
