# ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

## 🌊 Экран 1: КОЛОДЕЦ
- По центру — колодец (эмодзи 🪣 или SVG). По клику на него:
  * Анимация всплеска воды
  * +1 вода в тару (с учётом уровня насоса)
  * Звук плеска
- Справа — индикатор тары: `текущая / максимум` (старт: 0/10)
- Кнопка «Вылить в бочку» — переносит воду в общий запас
- Кнопка «Перейти на ферму» → переключает на Экран 2
- Пассивный доход: каждые 5 сек +1 вода (если есть апгрейд)

## 🌱 Экран 2: ФЕРМА
- Сетка 3x3 клетки (расширяется за монеты)
- В каждой клетке можно посадить растение (выбор из меню)
- Растения имеют стадии: 🌱 → 🌿 → 🍎 (визуально через эмодзи)
- Полив: клик по растению тратит воду из запаса
- Без воды растение не растёт (таймер замирает)
- Время роста:
  * Морковь: 30 сек, 2 воды, урожай 3 шт
  * Яблоня: 2 мин, 10 воды, урожай 10 шт
  * Пшеница: 1 мин, 3 воды, урожай 5 шт
- Кнопка «Собрать всё» — собирает урожай в инвентарь
- Случайные события (10% шанс при сборе):
  * «Золотой урожай» — x2 к количеству
  * «Вредители» — -30% урожая

## 🏪 Экран 3: РЫНОК
- Список товаров из инвентаря с текущей ценой
- Кнопка «Продать всё»
- Кнопка «Продать выбранное»
- Динамические цены: каждые 60 сек цены меняются в диапазоне ±30%
- Отображение монет в шапке
- Кнопка «Улучшения» → модалка с магазином апгрейдов

## 🛠️ МАГАЗИН УЛУЧШЕНИЙ (модалка)
Реализовать апгрейды по формуле: `цена = база * (1.15 ^ уровень)`

| Апгрейд | База цены | Эффект за уровень |
|---------|-----------|-------------------|
| Насос | 10 | +1 воды за клик |
| Тара | 25 | +10 к макс. объёму тары |
| Удобрение | 50 | -10% времени роста (мин. 5 сек) |
| Грядка | 100 | +1 клетка на ферме |
| Авто-полив | 500 | -1 воды на полив (мин. 1) |

# 💰 ЭКОНОМИКА (строго по цифрам)

## Базовые цены продажи (до динамического колебания):
- Морковь: 3 монеты за шт
- Яблоко: 5 монет за шт
- Пшеница: 2 монеты за шт

## Стартовые условия игрока:
- Монеты: 0
- Вода в общем запасе: 0
- Тара: 10
- Насос: уровень 1 (+1 за клик)
- Грядок: 3 (из 9 доступных)

## Прогрессия:
- Ожидаемое время до первого апгрейда «Насос»: ~20 кликов
- Ожидаемое время до первой яблони: ~5 минут
- Ожидаемое время до первого престижа: ~2 часа (пока не реализуем, просто заложить)

# 🎨 ВИЗУАЛ И UX
- Цветовая палитра: мягкие зелёные (#8BC34A), земляные (#8D6E63), 
  небесно-голубые (#4FC3F7), фон — кремовый (#FFF8E1)
- Шрифт: системный sans-serif, крупный (16px+ для читаемости)
- Все кнопки — с hover-эффектом и тактильным откликом (scale 0.95 при клике)
- Анимации: плавные, 200-300ms, ease-out
- Всплывающие числа при доходе («+5 💧», «+10 🪙») — floating text анимация
- Звуки: короткие (50-150ms), приятные, не раздражающие

# 📱 МОБИЛЬНАЯ АДАПТАЦИЯ
- Все кликабельные элементы ≥ 44x44 px
- Поддержка touch-событий без задержки 300ms
- Viewport meta tag настроен
- Ориентация — портретная (но работает и в ландшафтной)

# 💾 СОХРАНЕНИЕ
- Автосейв каждые 10 секунд в localStorage
- Сохранять: монеты, воду, уровень грядок, инвентарь, уровни апгрейдов, 
  состояние каждого растения (тип, стадия, время до сбора)
- При загрузке — рассчитать оффлайн-прогресс (сколько воды накапало, 
  сколько растений выросло за время отсутствия)

# ⚠️ ОГРАНИЧЕНИЯ (ЧТО НЕ ДЕЛАТЬ)
- НЕ использовать внешние библиотеки (jQuery, Lodash и т.д.)
- НЕ загружать внешние изображения (только эмодзи, SVG inline, CSS-графика)
- НЕ делать мультиплеер, бэкенд, авторизацию
- НЕ усложнять — сначала рабочий MVP, потом красота
- НЕ писать код больше 300 строк в одном файле (разбивай на модули)

# ✅ КРИТЕРИИ ГОТОВНОСТИ MVP
1. Игра запускается командой `npx serve` в корне проекта
2. Можно кликать на колодец → вода копится
3. Можно перейти на ферму → посадить морковь → полить → собрать
4. Можно перейти на рынок → продать морковь → получить монеты
5. Можно купить апгрейд насоса → получать больше воды за клик
6. Прогресс сохраняется после перезагрузки страницы
7. Нет ошибок в консоли браузера
8. Работает на мобильном (проверить через DevTools → toggle device)
