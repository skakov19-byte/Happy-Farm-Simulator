# ЗАДАЧА: Замена графики на рисованную (SVG)

Замени всю примитивную графику (эмодзи, простые фигуры) на детальные SVG-иллюстрации.
Все ассеты должны быть нарисованы через inline SVG в HTML/CSS.
Стиль: уютный, мультяшный, с мягкими тенями и градиентами.

## 🎨 ОБЩИЕ ТРЕБОВАНИЯ К СТИЛЮ

### Цветовая палитра
- Основные цвета: тёплые, насыщенные, но не кислотные
- Тени: мягкие, полупрозрачные (rgba(0,0,0,0.1-0.3))
- Градиенты: линейные, сверху вниз, для объёма
- Обводка: тонкая (1-2px), тёмная (#2c3e50 или #34495e)

### Технические требования
- Все SVG — inline в HTML (не внешние файлы)
- ViewBox: 100x100 для иконок, 800x600 для фонов
- Адаптивность: width="100%", height="auto"
- Оптимизация: минимум узлов, без лишних групп

## 🌊 ЭКРАН 1: КОЛОДЕЦ

### Фон (800x600)
Нарисуй деревенский пейзаж:
- Небо: градиент от голубого (#87CEEB) к белому (#E0F6FF)
- Холмы: 3 слоя зелёных холмов с градиентами (#7CB342, #8BC34A, #9CCC65)
- Солнце: жёлтый круг (#FFD54F) с лучами в верхнем левом углу
- Облака: 2-3 белых облака с мягкими тенями
- Трава: текстура из множества коротких линий внизу

### Колодец (200x300, по центру)
Детальный деревянный колодец:
- Основа: каменный круглый фундамент (#78909C, #90A4AE)
- Стены: деревянные брёвна (#8D6E63, #6D4C41) с текстурой
- Крыша: треугольная, черепичная (#A1887F, #8D6E63)
- Ведро: металлическое (#B0BEC5, #90A4AE), висит на верёвке
- Верёвка: изогнутая линия (#5D4037)
- Ворот: деревянный цилиндр с ручкой
- Тень: под колодцем, полупрозрачная

### Анимация колодца
- При клике: ведро опускается, вода плещется
- Создай 2 состояния SVG (ведро вверх/вниз)
- Переключение через CSS класс .well-active

## 🔧 ИНТЕГРАЦИЯ

### В HTML
Замени все эмодзи на `<img src="/assets/svg/...">` или inline SVG.

### В CSS
Добавь классы для анимаций:
```css
.well-active { animation: wellPump 0.5s ease-out; }
@keyframes wellPump {
  0% { transform: translateY(0); }
  50% { transform: translateY(20px); }
  100% { transform: translateY(0); }
}

.plant-ready { animation: plantBounce 1s infinite; }
@keyframes plantBounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-5px); }
}

.coin-flying { animation: coinFly 1s ease-in forwards; }
@keyframes coinFly {
  0% { transform: translate(0, 0) scale(1); opacity: 1; }
  100% { transform: translate(var(--fly-x), var(--fly-y)) scale(0.5); opacity: 0; }
}
```

### В JavaScript
Обнови функции рендера, чтобы использовать новые SVG вместо эмодзи.

## ✅ КРИТЕРИИ ГОТОВНОСТИ

1. Все эмодзи заменены на SVG-иллюстрации
2. Каждый экран имеет уникальный детальный фон
3. Колодец выглядит как настоящий деревянный колодец
4. Грядки имеют объём и текстуру
5. Рынок выглядит как рыночная площадь с прилавками
6. Монеты похожи на доллары (золотые с "$")
7. Все растения имеют 3 стадии роста
8. Анимации работают плавно
9. Нет визуальных багов (наложения, обрезания)
10. Игра работает на мобильном (SVG масштабируются)

## ⚠️ ВАЖНО

- НЕ используй внешние изображения (только inline SVG)
- НЕ ломай существующую функциональность
- Сохрани все обработчики событий
- Тестируй после замены каждого элемента
- Если SVG слишком сложный — упрощай, но сохраняй узнаваемость
